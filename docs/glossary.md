# Glossary

Tap a term to reveal it (works on GitHub mobile).

<details><summary><b>OneAgent</b></summary>

Single agent per host; auto-discovers processes and services; captures traces, metrics, logs.

</details>

<details><summary><b>ActiveGate</b></summary>

Proxy/routing component; remote monitoring (cloud APIs, extensions) and synthetic private locations.

</details>

<details><summary><b>Smartscape</b></summary>

Live topology map: hosts, processes, services, apps and dependencies.

</details>

<details><summary><b>Davis AI</b></summary>

Causal AI engine; correlates anomalies into one problem with a root cause.

</details>

<details><summary><b>Problem</b></summary>

Davis-raised incident grouping related events, with impact and root cause.

</details>

<details><summary><b>Baselining</b></summary>

Automatic learning of normal behaviour so alerts fire without manual thresholds.

</details>

<details><summary><b>Grail</b></summary>

Data lakehouse for logs, metrics, events, traces; queried with DQL.

</details>

<details><summary><b>DQL</b></summary>

Dynatrace Query Language: piped commands, e.g. fetch | filter | summarize.

</details>

<details><summary><b>Notebook</b></summary>

Analysis canvas for DQL, metrics and markdown; for exploring.

</details>

<details><summary><b>Dashboard</b></summary>

Shareable tiles with variables, built on DQL.

</details>

<details><summary><b>Bizevents</b></summary>

Business events (orders, payments) captured and queried with DQL.

</details>

<details><summary><b>RUM</b></summary>

Real User Monitoring: real sessions and actions in browser and mobile apps.

</details>

<details><summary><b>Key user action</b></summary>

A flagged important action with its own thresholds and charts.

</details>

<details><summary><b>Synthetic monitor</b></summary>

Scripted browser or HTTP check run from chosen locations on a schedule.

</details>

<details><summary><b>Distributed trace</b></summary>

End-to-end path of one request across services (PurePath).

</details>

<details><summary><b>Workflow</b></summary>

Automation triggered by events or a schedule, e.g. notify on a problem.

</details>

<details><summary><b>Management zone</b></summary>

Classic access/data scoping; superseded by segments and IAM policies in the new platform.

</details>
