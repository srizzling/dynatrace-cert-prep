# Dynatrace Associate study guide

Book for Fri 4 Dec. You've used Dynatrace all year, so the marks to win are DQL in the new apps, exact naming in the practical, and the trivia you never touch day to day.

## Exam at a glance

| Item | Detail |
| --- | --- |
| Written | 60 multiple-choice and multiple-response questions |
| Scoring | Multiple-response: each right pick earns partial credit, each wrong pick deducts the same. Don't guess. |
| Practical | 10-15 hands-on tasks in a live 3rd gen tenant. Open book: official docs allowed |
| Practical tasks | Build DQL queries, dashboards (with variables) and notebooks; find settings, monitors and user actions in the UI |
| Grading | Strict matching. A dashboard named ax-Dashboard instead of ax-dashboard scores zero |
| Proctoring | Online with webcam, English only. Laptop, not phone |
| Retake | About US$200 per attempt. You get a score report by topic area |
| Validity | 2 years |

## The 10 official topic areas

1. **The Dynatrace Platform**: Navigating the platform, what Dynatrace is, Docs, Hub and Support Center.
2. **Monitoring & Infrastructure Observability**: Dynatrace Apps, OneAgent, infrastructure and Kubernetes monitoring. App Spotlight videos (about 4 h, watch on the phone).
3. **Notebooks & Dashboards**: Notebooks and Dashboards docs, Notebooks update video (40 min). Variables and tile types.
4. **Business Analytics & DEM**: Business events, RUM (define applications, key user actions), synthetic monitoring.
5. **Data, Reporting & Analysis**: Dashboard report subscriptions, Dashboards API and OAuth clients, user behaviour analysis, session segmentation, metrics on Grail.
6. **DQL**: A Practical Guide to DQL (video, 36 min) plus the DQL docs. Heaviest in the practical.
7. **Security**: Application Security, third-party and code-level vulnerabilities, Davis Security Advisor and Security Score, Security Investigator.
8. **Automation**: AutomationEngine, Workflows docs, Workflows Quick Start hands-on.
9. **Ingestion**: Log ingestion, cloud integrations, VMware vSphere monitoring.
10. **Other**: Smartscape topology, log content analysis, Dynatrace Hub.

## Exam tips

- Learn the new (3rd gen) apps, not Classic. The exam tenant is the latest version.
- Read every practical instruction twice. Copy names character for character.
- Skip hard practical tasks and come back. Time runs out there first.
- Stuck on a query? Notebook > + > Metric, pick the metric, then adapt the DQL it generates.
- Some 'practical' tasks are just finding an answer in the UI: a monitor's locations, a query's table, a user action.
- Expect rote MCQs on retention periods, timeouts, time-frame options and support tiers.
- On multiple-response questions, tick only options you're sure of.
